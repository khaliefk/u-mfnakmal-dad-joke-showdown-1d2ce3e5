## The entry

`main.py` writes one original dad joke to `/output/entry.txt`:

> I asked my wife why she keeps a ladder in the kitchen, and she said it's for when the steaks are high.

One sentence, 102 characters, inside the 200 character cap. The joke
turns on the steaks/stakes pun, told as a straight exchange at the dinner
table, with the punchline landing at the end.

## How to run

```sh
python3 main.py
```

That writes the joke to `/output/entry.txt`. The program is
deterministic: every run writes the same text.
